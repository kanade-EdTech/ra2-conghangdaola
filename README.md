红警 2 国家、部队、建筑与特色排名工具，当前发行版本 `0.4.3`。支持 B 站 Toy 和小红书离线小工具，使用“夯、顶级、人上人、NPC、拉”五档和待排名区。

0.4.3 修复长图导出弹窗：图片独立滚动，关闭、翻页、保存按钮保持可见。Toy 为完整榜单，小红书沿用精简范围与 138 张共享图标。发行包为 `release/ra2-tier-list-toy-0.4.3.zip` 与 `release/ra2-tier-list-xhs-0.4.3.zip`。详见 [发行说明](docs/0.4.3-发行说明.md) 和 [界面检查记录](docs/2026-10-18-界面检查.md)。

2026-10-18，Toy 0.4.3 已按“公开可见”提交审核，返回 `auditing`。[本轮提交预览](https://www.bilibili.com/toy/preview/preview_uAyLxel8/index.html)，[正式作品入口](https://www.bilibili.com/toy/ra2-conghangdaola/index.html)；正式入口在审核通过后更新。

小红书另提供 **0.4.2 优化版**：[包体优化记录](docs/0.4.2-小红书包体优化.md)。沿用 [0.4.1 精简范围](docs/0.4.1-小红书导出记录.md)，保留国家榜、常规榜、国家特色和 T4，移除其他单位及特殊建筑。相同图标跨版本共用文件，图片从 226 张减至 138 张，包为 `release/ra2-tier-list-xhs-0.4.2.zip`（约 649 KB，比 0.4.1 缩小 39.5%）。用 `npm run build:xhs`、`npm run check:xhs`、`npm run package:xhs` 重建。以下 0.4.0 范围说明对应完整版本。

## 使用方式

- 顶部入口为国家榜、常规榜、特色榜。特色榜分为国家特色、T4 科技、其他单位、特殊建筑。
- 国家榜按原版 9 国、尤复 10 项独立保存，默认名称“国家强度排序”。
- 常规榜含普通单位、国家专属项目、T4 和遭遇战建筑：原版 89 项，尤复 126 项。用类别、阵营、科技阶段筛选，选择后点“应用筛选”。“清除筛选”返回该版本该榜的全部范围。
- 类别包括步兵、地面载具、海军、空中单位、普通建筑、防御及超级武器；科技包括基础、雷达后、作战实验室后、间谍偷实验室后。可勾选屏蔽国家专属单位与建筑。
- 同版本、同类榜共用一份完整排名。切换筛选不会删除隐藏项目；档位、同行顺序和待排名区顺序自动保存，刷新后恢复。筛选内调整同行顺序后，完整行按最新可见顺序合并，隐藏项目的相互顺序保留。
- 国家特色支持“综合／红警 2 原版／尤里的复仇”三份独立九项榜，按阵营和类别筛选。空版本首次初始化继承当时综合排名；之后独立，主动重置也不会自动重新继承。
- T4 子榜按版本独立，原版 4 项、尤复 3 项，按阵营和类别筛选。它与常规榜中的 T4 使用不同排名。
- 其他单位包含平民人物、车辆、动物和战役／隐藏单位，原版 52 项、尤复 78 项，按阵营、类别和来源筛选；弹体与舰载子机排除。
- 特殊建筑收录中立和战役建筑，原版 233 项、尤复 319 项，按阵营、类别和中立／战役来源筛选。重复 ID、灯光和不可见辅助对象排除。
- 无独立图标、借用无关单位图片或图标加载失败时，显示阵营标志；海报使用同样的回退方式。
- 从卡片任意位置直接拖入档位，无需长按；点按选中后也可调档、前移、后移或移回待排名。第二根手指、Esc、取消按钮及窗口中断会取消拖动；拖到视口上下边缘自动滚动。
- 同一榜内撤销最多 20 步，可跨筛选撤销，只保留在当前会话。重新排名只清当前筛选匹配项、保留标题，可撤销。
- 长列表每批显示 40 项。导出包含当前筛选的全部项目（含待排名），每页最多 50 项，逐页预览与保存；可选 1080 或 720 像素宽度。Toy 提供浏览器保存，小红书使用宿主相册能力，无宿主时保留预览供系统截图。

## 本地构建

应用无第三方运行依赖，需要 Node.js；打包需要 Python 3。

```powershell
npm test
npm run build
npm run check
npm run dev -- 4175
```

入口：`http://127.0.0.1:4175/dist/toy/index.html`，小红书为 `/dist/xhs/index.html`。验证通过后执行 `npm run package`。

离线包：`release/ra2-tier-list-toy-0.4.0.zip`、`release/ra2-tier-list-xhs-0.4.0.zip`。各 265 文件，约 1.18 MB，以根目录 index.html 为入口，只包含使用到的离线资源。哈希见 `release/0.4.0-artifact-manifest.json`。

## 数据与存档

现行数据生成入口是 `python scripts/prepare-0.4-catalog.py`，需要本机原始游戏档案和既有提取环境；两个旧生成脚本直接运行时转入现行入口。普通构建不依赖游戏安装。

`data/unit-catalog.json` 保留历史审核的普通单位／T4 输入；`data/runtime-unit-catalog.json` 是加入国家标记、科技阶段、其他单位及建筑后的完整运行名录。原始素材在 `assets/unit-icons/`，国旗和阵营图标来源分别见 `assets/asset-manifest.json`、`assets/factions/manifest.json`。逐条额外收录处置在 `data/0.4-catalog-audit.json`。

本地存档升级为 `ra2-tier-list:save:v3`，保留旧 v1／v2 键。旧独立筛选榜没有修改时间，迁移采用活动筛选优先、其他已排项目填补的规则，无法推断旧冲突项目真实的最后操作时间。损坏或未知版本会保护原数据；写入失败会提示。存档仅保存在当前平台／设备。

## 验证与预览

0.4.0 已通过 28 项内置测试、192 项本轮浏览器断言、两平台静态检查和 ZIP 审计。专项脚本为 `scripts/browser-0.4.0.js`、`browser-0.4.0-storage-touch.js`、`browser-0.4.0-icons.js`，并复用了 `browser-interaction.js`。其他旧脚本仍可能含旧版本范围断言，应按其历史版本阅读。

实际浏览器为 Chrome 155.0.8059.40；覆盖 320／390／430 像素宽度、Pointer／Touch 回退、真实触屏拖放、v1/v2 迁移、筛选顺序和最大榜 7 页导出。未实测 B 站 App、小红书真机和 Chrome 61，相册桥接采用模拟验证。
