# 0.2.0 触屏交互半重构验收记录

日期：2026-10-13  
版本：0.2.0  
结论：本地实现与两个平台候选包完成。初次交互验收为 15 项单元测试、96 项浏览器检查通过；标题恢复修复另通过 16 项单元测试与 12 项浏览器定向检查。尚未上传或提交平台审核。

## 交付变化

- 整张卡片直接拖动，触摸无需长按；点按先选中，底部操作区提供定档与排序。
- 拖动显示原位占位、浮动卡片、目标区域和插入位置；无效落点回位，跨档与换行重排均可用。
- 拖动仅更新预览，松手最多提交一次。原位松手、取消和双指打断不会新增撤销。
- 保留标签／空白处原生滚动；停指在可用视口上下边缘可继续自动滚动，取消即停止。
- 输入、手势状态机、几何命中与控制器拆分；Pointer 捕获有回退，Touch 路径按触点标识跟踪。
- 支持丢失捕获、失焦、页面隐藏／离开、视口变化和应用动作主动取消；提供可重复安全调用的销毁接口。
- 修复实际触摸测试发现的“拖动后按钮偶尔不产生原生点击”：触摸按钮松手激活一次，并抑制后续兼容点击；新的真实触摸不被旧令牌吞掉。
- 延续国家素材、原版 9 国／尤复 10 项、标题、撤销、存档及海报生成。保留 schemaVersion 1 和原存储键，0.1.0 草稿无迁移恢复。

参考 tldraw 的交互组织方式，使用独立编写的原生实现，未加入 React 或 tldraw SDK。卡片落位直接进入目标布局；计划建议的落位过渡动画未增加，保留即时反馈。

触摸回退测试同时移除 PointerEvent 与 visualViewport，验证 Touch.identifier 和视口回退路径；这只验证回退分支，不证明 Chrome 61 整体兼容。普通浏览器主流程覆盖 320、375、390、430、768、1280px 无横向溢出。

小红书测试使用受限 CSP、模拟桥接成功／拒绝及已加载页面断网操作。未实际执行小红书离线 ZIP 冷启动或相册授权。主流程没有未捕获页面错误或业务资源 HTTP 错误。
