科技按正常前置链划分：基础、雷达、作战实验室。展开通用前置别名；特殊国家结合 RequiredHouses／ForbiddenHouses；忽略战役地图专用的 PrerequisiteOverride 路径。遥控坦克经控制中心的前置链归基础。海空身份独立于引擎注册表，飞行步兵具有步兵和空中标签。

T4 是间谍解锁集合，原版四项、尤复三项；尤复尤里 X 不属于 T4。常规查询始终排除 T4。T4 获取可涉及占领敌方生产设施及间谍取得敌方科技，按规则合法条件收录，不代表每个初始国家直接自建所有前置。

尤复跨阵营 Owner 的常规单位按正常生产建筑确定身份。月球步兵及要求敌方兵营的尤里军犬排除；菜单图标存在不能证明普通可生产。平民、派生载机、弹体等逐条记录排除理由。
