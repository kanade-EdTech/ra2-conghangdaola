## 一、总提示词

```text
请在 F:\VS_Code_Project\ra2-conghangdaola 项目中实现红警 2「从夯到拉」0.3.0：保留现有国家榜，新增先按游戏版本分开、再按类别／阵营／科技阶段三个选项确定范围的常规单位榜，增加通过帅气隐藏入口进入的独立 T4 榜，以及两版共用的九种国家特色榜。目标是完整实现、验证并生成 Toy 与小红书两个本地候选包。

先阅读用户最新答复、适用的 AGENTS.md、README.md、docs/0.3.0-开发计划.md、docs/单位图标采集说明.md、现有源码、构建脚本和测试。检查工作区已有修改，不重置、不覆盖历史版本包，不清理用户真实浏览器草稿。需要改写小红书产物或操作真实浏览器时，读取并遵循适用的 minitool-zip-builder、playwright 技能；只有实际需要 Toy 平台操作时才读取 toy 技能。

【需求决定】
用户已确认：游戏版本是单位范围的首要边界；在版本内通过类别、阵营、科技阶段三个选项取交集。科技按基础／雷达后／作战实验室后三阶段划分；采用遭遇战常规范围及四种类别。T4 指间谍偷取科技后解锁的特殊单位，必须从常规名单（包括“全部”）剔除，通过帅气隐藏入口独立排序，原版和尤复各自保存。九种国家特色继续两版共用一份榜。无需重复确认，不实现 TechLevel 数值筛选，不按版本拆出两张特色榜。

实施范围：原版与尤复均覆盖，分别建立常规与 T4 两个无交集的单位集合。常规阵营为盟军／苏军／尤里，类别为步兵／地面载具／海军／空中单位，科技为基础／雷达后／作战实验室后；普通科技菜单不出现“特殊获取”或 T4。普通建筑不进单位榜，但法国巨炮进入特色榜。默认不加入战役、平民、隐藏废弃条目和派生弹体／舰载子机。所有名录决定必须有来源和排除理由。

【产品与筛选】
1. 提供国家榜／单位榜／国家特色榜三个常驻入口，以及独立 T4 隐藏入口。国家榜、常规单位榜、T4 榜始终以原版／尤复为顶层边界；特色榜收起版本切换，显示“原版／尤复共用”，并保留最近游戏版本供离开后恢复。原国家榜原版 9 国、尤复 10 项，默认标题仍为“国家强度排序”。
2. 常规单位榜界面依次显示类别、阵营、科技阶段三个单选，各有“全部”。先限定当前版本和 regular 集合，再取三项交集；所有“全部”都不能纳入 T4 或另一游戏版本。结果决定实际可排序集合、进度、待排名、重置和导出。支持某阵营某类、跨阵营某科技某类、三项交集和本版全部常规单位，不只做固定预设。
3. 用户修改筛选时预览数量，应用后进入对应榜单；国家榜和 T4 榜按版本、常规单位榜按版本和组合独立保存，特色榜跨版本共用一份。切回恢复原结果，不把一个大榜的排名自动同步给其他单位子榜。
4. 空结果不创建可编辑空榜，不导出，不显示 100% 完成；单项目仍可操作。原版没有尤里阵营，跨版本无效条件要明确降级并提示。
5. 阶段筛选表示最低解锁阶段恰好为该阶段，不累计包含低阶段。TechLevel 原值仅用于数据核对，不提供数值筛选，不能靠 1–3／4–6／7–10 猜科技阶段。
6. 不预置强弱结论；所有新榜初始都在待排名区。自定义标题继续支持 30 个 Unicode 码点，返回旧组合不得覆写标题。

【数据整理：先解决正确名单，再写界面】
1. 以 assets/unit-icons/ra2/manifest.json 和 yr/manifest.json 作为素材索引，保留采集原件；新增可复查的整理数据、人工修正规则和按版本的纳入／排除报告。
2. 采集量 64／94 个有图标单位 ID 不是最终遭遇战单位数，TechLevel 非负也不能证明可用。两个版本全部登记 ID 都要有处置记录，不能只筛出有图标条目就宣布“全部”。
3. 用本机规则与既有只读解析工具补充 Owner、RequiredHouses、ForbiddenHouses、Naval、MovementZone、飞行标记、生产前置、BuildLimit、全部 RequiresStolen*Tech 等字段。现有 manifest.factions 仅由 Owner 推导，不能直接用于产品。
4. 核对正常生产链、国家限制、间谍科技条件和例外。展开 RADAR／TECH 等前置别名时区别任选组与同时满足，处理递归和未知节点；特殊控制建筑需要明确归类依据。
5. 玩家类别使用标签而不是直接复用 InfantryTypes／VehicleTypes／AircraftTypes：航母是海军，基洛夫／飞碟／武装直升机是空中；火箭飞行兵同时可在步兵与空中类别出现，全单位榜和单次查询内按 itemId 去重。两栖能力不自动意味着海军。
6. 用版本和游戏 ID 建立稳定身份，保留原始名称，提供简体显示名称。工程师等同名项目带阵营标识；共享图标不合并不同单位。原版和尤复相同 ID 的含义分别核对。
7. 普通图标用于单位卡片，三星不另造一张卡。确实应纳入但缺图的条目单独处理，不能借无关图标或静默漏掉。
8. 最终生产名录生成外置经典脚本，构建不依赖本机游戏安装，浏览器不解析 MIX、不联网、不用 fetch 加载 JSON。
9. 增加逐版 rankingPool=regular／t4／excluded。T4 必须核对本版实际间谍解锁条件，不能仅凭 TechLevel 数值、单个标记或 gameId 认定；特别核对两版 YURIPR 的不同身份。T4 的 techStage 不伪填为普通三阶段。给出每版常规／T4 的名单、数量和分类依据，断言两集合无交集；不能只从界面隐藏 T4 而仍计入进度或存档允许集合。

【T4 独立榜与隐藏入口】
按计划第3.4节实现“机密档案”彩蛋：在常规单位条件摘要右下角放低调的44px徽章，面板折叠和零匹配仍可点。采用深色金属、琥珀警戒斜纹、暗红封签和本地CSS／SVG图形；点按后封签展开、扫描线掠过，180–240ms内显露“T4 · 机密科技”和“进入 T4 排名”。显示当前版本及“间谍科技单位 · 独立排名 · 不计入常规榜”。不循环闪烁、不放音效，减少动态效果时直接显示。
不依赖强制长按、多连击或 hover。徽章可键盘操作，标明展开状态；关闭恢复焦点，切版／切模式清理动画和面板，打开时取消未提交拖拽。彩蛋不是真实权限检查。
进入T4后展示本版全部已核实T4，不继承普通榜三个条件，不增加T4子筛选。保留版本选择，原版与尤复各自排名、撤销、重置、保存和导出；刷新可直接恢复T4。返回常规榜恢复当前版本最近应用的筛选和排名，不能重置。T4未核实有可用项时明确空状态，不用另一版填充。
使用<version>|t4作为榜单键，context仅含mode=t4和version，项目沿用unit:<version>:<gameId>。同版regular与t4集合无交集。给出隐藏徽章、展开状态和T4榜截图；不能只添加普通T4文字按钮就视为视觉完成。

【九种特色】
固定九项：美国伞兵、英国狙击手、法国巨炮、德国坦克杀手、韩国黑鹰战机、苏俄磁能坦克、伊拉克辐射工兵、古巴恐怖分子、利比亚自爆卡车。原版和尤复共用同一张榜，不额外添加尤里为第十项。
使用计划第 5 节的版本内素材映射。美国是技能 AmericanParaDropSpecial，对应 cameo 为 APARICON，使用 cameos/aparicon.png；不能误用 paraicon 或美国大兵。巨炮引用 buildings/gtgcan.png。其余分别引用 SNIPE、TNKD、BEAG、TTNK、DESO、TERROR、DTRUCK 的普通图标。
特色卡片显示国家与特色名，允许来源为单位／建筑／技能，使用不含版本的 signature:<countryId> 身份，全局共九项。两版对应的九组图标清单哈希已核对一致，固定引用 ra2 素材，保留两版来源映射，不随最近游戏版本切图。同单位在特色榜和单位榜评分互不覆盖。
特色榜仅有 shared|signatures 一个键，标题、排名、档内顺序、会话撤销和重置操作全部共享；不要复制两份再做同步。特色海报注明“红警 2／尤里的复仇 · 共用特色榜 · 9 种国家特色”，不误带最近访问的单一版本或单位筛选。

【核心、存档与兼容】
1. 抽出通用 getItem、getEligibleItemIds 和规范化 context／boardKey。排名核心接收允许 ID 集合；五档加待排名区内，每个允许项目恰好出现一次。
2. 移动索引仍是移除源项后的插入位置。一次有效落位一条撤销，取消、无变化零历史。撤销每榜最多 20 次，仅存在当前会话；重置只作用当前榜，保留标题，可撤销。
3. 使用 schemaVersion:2 和 ra2-tier-list:save:v2，按计划第 6 节迁移 v1。v2 优先；只有不存在 v2 才读取 v1。v1 原键保留，迁移校验和成功写入之前不能宣称已保存。
4. 国家榜迁移保留标题、档位、顺序和当前版本；旧自带喜好榜标题精确迁为“国家强度排序”，自定义／空标题沿用原行为。
5. 损坏、未来格式、写入失败或未知名录版本保护原数据。不能回退旧存档覆盖新存档，不能为增加类别清空所有旧榜。名录升级有明确迁移与可恢复备份。
6. 各组合按需创建，不预生成笛卡尔积。存档只含 ID、条件与排名；不持久化整套名录、图片、选择、拖动和撤销。配额不足明确提示，不静默删除其他榜单。
7. 特色 context 固定为 mode=signatures、scope=shared，不含 version 和单位筛选；规范化时移除不适用字段。顶层 lastGameVersion 单独保留最近游戏版本，v1 的 activeVersion 迁入该字段；刷新共享特色榜后返回国家／单位榜仍恢复原版本。
8. T4 context 移除普通单位筛选字段，仅按version查询t4集合。新增按版本保存的lastRegularContexts，记录各版最近应用的常规筛选；进入T4不反写该字段，返回恢复对应榜。T4可作为activeBoardKey恢复，徽章展开和动画进度只留内存。

【界面、触屏与性能】
1. 保留原生 HTML/CSS/ES2017、现有轻量构建和 0.2.0 交互，不引入新框架或 tldraw SDK。
2. 将 countryById／data-country 依赖统一到通用项目；检查卡片、选中、焦点恢复、对话框、输入适配、幽灵卡与导出，不只替换可见文案。
3. 保持整卡触摸拖动、点按选中、底部动作、目标高亮、插入线、边缘滚动、键盘操作和多指取消。国旗与 60×48 单位图标各自保留比例，长名称和同名单位可识别。
4. 拖拽会话绑定完整 boardKey；切版本、模式、筛选、重置、导出前统一取消未提交手势。旧会话延迟事件不能写入新榜。
5. 保持单一文档滚动层及 44px 可触摸／滚动路径。最大实际名单下检查多行布局、最远档位和连续拖点；没有性能证据前不要加入虚拟列表。

【导出与产物】
1. 海报读取启动时榜单快照；国家／常规单位榜标注版本、榜单类型、适用的筛选条件与完成数量，完整包含待排名且常规单位不包含T4。T4海报标注当前游戏版本和“T4 间谍科技 · 独立榜”，不用普通榜遗留条件。特色海报使用固定的两版共用说明，特色卡同时显示国家和特色名。
2. 按需加载和缓存当前榜图标；导出前先计算尺寸，保留 4,000,000 像素预算。1080px 超限可选择 720px；720px 仍超限则按完整卡片行分页，带页码、必要档位标记与条件摘要，逐张生成释放。不得截断单位或删除待排名内容。
3. 两平台沿用各自保存方式，小红书保留宿主桥能力不足时的预览回退；不能把 Toy 下载代码混入小红书包。
4. 只打包实际引用普通图标、特色图标和国旗，不打入完整采集库、SHP、三星素材、CSV、文档、绝对本机路径和脚本。同步严格生产清单与脚本顺序，不删除审计来让构建通过。
5. 先保留现有 2 MiB 未压缩预算并测量完整包，必要时通过引用裁剪和资源去重优化；需要变更预算时给出实际依据，不把项目预算冒充平台限制。

【实施与交付】
按计划 M0–M5 完成，先名录与数据正确性，再通用核心和迁移，再 UI、导出、构建。测试集中覆盖真实风险：版本边界、常规／T4无交集、“全部”排除T4、分类、阶段、国家限制、条件交集、榜单隔离、彩蛋进入返回、迁移失败和保护、长名单触摸、导出完整性及九项特色。
```

## 二、分阶段提示词

### M0：确认实施口径与基线

```text
执行 docs/0.3.0-开发计划.md 的 M0。采用第1节已确认决定：版本为首要边界，类别／阵营／科技阶段三项筛选，常规单位排除T4；T4是间谍科技单位，通过隐藏入口独立排名，两版分开；九特色两版共用。不重复询问，也不保留相反的旧草案假设。检查实际 0.2.0 源码、未提交修改、构建清单、草稿格式和最新标题迁移。准备独立的旧草稿样例，包含两版排名、自定义标题、旧默认标题、空标题、损坏及未来格式。记录当前必要基线检查结果，不改用户真实草稿，不先升级版本号，不提前实现后续阶段。
```

### M1：可复查的单位和特色名录

```text
执行计划 M1，仅完成数据整理及必要的生成工具。逐条覆盖两版登记 ID，为纳入、排除和待核对提供理由，不能用“有图标且 TechLevel>=0”替代完整名单审核。补充国家限制、海空身份、完整前置和 RequiresStolen*Tech 等字段，保留采集档案，新增产品名录和人工修正规则。
核对 SNIPE、TTNK、CARRIER、ZEP、JUMPJET、工程师、两版 YURIPR、尤复 PTROOP／CIVAN，以及遥控坦克等特殊建筑前置。将用户类别、科技阶段和原始 TechLevel 分离。建立一套不含版本的九特色身份，核对两版来源并固定共用图标，重点确认美国 APARICON 和法国巨炮。
分别审核两版间谍科技获得条件，建立rankingPool并输出常规和T4两份名单，不能把T4混入常规“全部”或三个阶段。两版同ID可有不同归类；所有已纳入单位只能属于本版一个池，待核对条目不得默认归常规。
输出 docs/0.3.0-单位名录核对.md 以及机器可读的名录／处置记录，说明最终数量及排除原因，检查每个引用图片存在、尺寸合理、版本对应正确。可有阶段性待核对项，但影响交付名单的问题不得到最终验收时仍被藏起来。不要根据待核对数据开始声称单位全覆盖。
```

### M2：通用排名、组合查询与安全迁移
