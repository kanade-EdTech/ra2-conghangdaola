# 0.3.1 顶部导航与特色子榜

日期：2026-10-15。状态：本地开发、双平台候选包和本次回归完成。

## 本次行为

- 将“国家榜、单位榜、特色榜”移到品牌栏下、介绍及版本设置之前，并在滚动时固定到顶部。
- 特色榜有三个子项：“国家特色、T4 科技、其他单位”。父级一直显示特色榜选中状态，返回时恢复最近访问的子项，刷新恢复当前子项。
- 国家特色继续两版共用九项。T4 继续分原版四项、尤复三项，顶部可直接进入，原机密档案彩蛋保留为附加入口。
- “其他单位”按用户确认范围，仅收录有菜单图标的战役／平民／隐藏及特殊支援单位，排除弹体及舰载子机。原版 11 项、尤复 21 项，分版本独立排名、撤销、重置和导出；不加入普通单位筛选。
- 无图标条目不收录；HORNET 与 ASW 是舰载子机，明确排除。运输机、米格支援机与侦察机不属于舰载子机，保留。XCOMET、UTNK 的完整规则具有单位属性，保留为隐藏战车；SCHD 以隐藏形态单列，名称标明形态，普通单位名单不增加重复项。
- 存档仍为 v2、名录 revision 1，原常规／T4／国家特色允许集合保持兼容；新增 `<version>|others` 草稿，不清空已有排名。
- 顶部导航遮挡范围参与拖拽命中与边缘滚动计算，防止在导航栏覆盖区错误落位。

## 数据与复现

`scripts/prepare-other-units.py` 根据原始采集清单及既有常规／T4 名录生成：

- `data/other-unit-catalog.json`：最终其他单位名单。
- `data/other-unit-audit.json`：全部剩余登记项的纳入／排除理由。
- `src/data/others.js`：离线生产数据。

重新生成时先运行 `python scripts/prepare-catalog.py` 更新常规名录，再运行 `python scripts/prepare-other-units.py`。日常构建直接使用已生成数据，不依赖本机游戏目录。
