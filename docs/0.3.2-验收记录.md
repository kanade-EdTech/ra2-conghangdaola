# 0.3.2 图标修正验收

日期：2026-10-15。

取消用其他单位菜单图代表战役人物、特殊车辆。原版 8 项、尤复 16 项改用阵营标志，包括磁暴步兵图所代表的将军／总统／保镖等，以及航母图所代表的维拉迪摩指挥舰。其他借用动员兵、犀牛、自爆卡车、军犬、武装直升机或运输机菜单图的特殊条目也按同一规则处理。

盟军人物采用盟军标志；维拉迪摩、罗曼诺夫和苏军特殊车辆采用苏军标志；奴隶和尤里军犬采用尤里标志；民用卡车与未指定阵营运输机采用通用阵营标志。普通磁暴步兵与航母保留自己的菜单图。

阵营标志从本机 CnCNet Resources 原样复制，来源与 SHA256 见 `assets/factions/manifest.json`。原菜单路径保存在 `data/other-unit-catalog.json` 的 sourceIconPath；实际显示路径为空时，通过 iconFaction 选择阵营标志。采集档案原件保留。名单和 ID 不变，原版其他单位 11 项、尤复 21 项，现有排名存档继续有效。

页面卡片、详情与拖动使用同一图标函数；图片加载失败时转为阵营标志，标志本身也失败则显示阵营文字，避免循环重试。海报也重试阵营标志并保持图像比例。

验证：28 项内置测试通过；Chrome 155 中两个平台共 42 项图标专项断言（含故意中断 HIND 图片加载、页面回退、海报实际绘图来源），以及 40 项导航／版本隔离／排名保存／导出回归断言通过。截图见 `output/playwright/0.3.2-faction-icons.png`。小红书 zip 审计无警告，Toy 预检无问题；未做 App 真机和 Chrome 61 实测。
