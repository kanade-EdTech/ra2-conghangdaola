## 1. 项目沿革与本轮目标

本项目是面向 B 站 Toy 和小红书小工具的离线 H5 排名工具，支持“夯、顶级、人上人、NPC、拉”和待排名区，保留本地草稿并生成结果图片。

| 阶段 | 已形成的功能或成果 |
| --- | --- |
| 首版 | 红警 2 原版、尤复国家榜；国旗素材；默认名称调整为“国家强度排序” |
| 0.2.0 | 参考 tldraw 的直接操作方式实现触屏拖动；使用原生轻量交互，未引入 tldraw 运行依赖 |
| 0.3.0 | 单位名录、类别／阵营／科技阶段筛选、T4 榜和九种国家特色榜；原版与尤复规则分离 |
| 0.3.1 | 国家榜、单位榜、特色榜置于顶部；特色榜分为国家特色、T4 科技、其他单位 |
| 0.3.2 | 无独立图标、借用其他单位图标的条目改用阵营标志；页面与海报统一回退；已于 2026-10-15 提交 Toy 审核 |
| 本轮 0.4.0 | 筛选间共享排名与同行顺序；加入建筑、全部平民单位、国家专属屏蔽、常规榜 T4 阶段及国家特色版本榜 |

0.3.2 提交返回的历史状态为 `auditing`，记录见 `release/toy-submission-0.3.2.json`；本轮重新查询作品列表返回 published；0.4.0 仍只生成预览，不能将该状态视为本轮审核通过。

本轮最终目标：筛选只改变显示范围，用户刚调整的档位和同行顺序在同版本、同类榜内持续有效；内容扩展后仍能在手机上完成拖动、筛选、刷新恢复和图片导出。

## 2. 已确认的用户需求

以下内容由用户直接确认，接续开发不应重新询问已确定的问题。

1. 改变筛选条件后，项目所在档位及同行位置保存在本地；筛选回来仍显示最新位置。
2. 同版本、同类榜共享一份排名，不再为每组筛选分别创建独立排名。
3. “单位榜”改名为“常规榜”。
4. 常规榜增加“普通建筑”“防御及超级武器”，按游戏内两类建造页划分。
5. 常规榜收录遭遇战可建造的建筑和所有国家专属单位，并提供屏蔽国家专属项目的复选框。
6. 中立建筑、战役建筑进入特色榜，作为独立榜存在。
7. T4 同时出现在常规榜中，科技筛选增加“间谍偷实验室后”；特色榜中的 T4 独立入口继续保留。
8. 国家特色按阵营／类别筛选；T4 按阵营／类别筛选；其他单位按阵营／类别／来源筛选。
9. 平民人物、车辆、动物全部纳入“其他单位”，缺图也收录。弹体和舰载子机继续排除。
10. 国家特色版本选项从左到右为“综合／红警 2 原版／尤里的复仇”。三份排名独立；空的版本存档继承综合榜排序。
11. 无独立菜单图或菜单图借用了无关单位时使用阵营标志；不能拿磁暴步兵、航母等图像凑数。

## 3. 本轮采用的具体实现约定

这些是根据确认需求采用的实施方式，需在验收中验证。

### 3.1 导航和榜单范围

| 主入口／子入口 | 版本 | 筛选 | 存档边界 |
| --- | --- | --- | --- |
| 国家榜 | 原版／尤复 | 不增加单位筛选 | 每版本独立 |
| 常规榜 | 原版／尤复 | 类别、阵营、科技阶段、屏蔽国家专属 | 每版本一份完整排名 |
| 特色榜 → 国家特色 | 综合／原版／尤复 | 阵营、类别 | 三份独立排名 |
| 特色榜 → T4 科技 | 原版／尤复 | 阵营、类别 | 每版本独立，与常规榜的 T4 排名分开 |
| 特色榜 → 其他单位 | 原版／尤复 | 阵营、类别、来源：战役／平民／隐藏 | 每版本一份完整排名 |
| 特色榜 → 特殊建筑 | 原版／尤复 | 阵营、类别、来源：中立／战役 | 每版本一份完整排名 |

“特殊建筑”是本轮给中立和战役建筑新增的子榜名称。原版尤里改仍属于 T4；尤复尤里 X 仍属于普通科技阶段的常规英雄，不应误纳入 T4。

国家专属屏蔽当前包含狙击手、坦克杀手、黑鹰、磁能坦克、辐射工兵、恐怖分子、自爆卡车、巨炮和美国专属空指部。美国伞兵作为国家特色能力保留在国家特色榜；美国大兵本身是常规单位，不能因其出现在伞兵中就全部屏蔽。

### 3.2 排名、筛选和同行顺序

- 持久化完整榜单；筛选结果是完整榜单的可见视图。
- 存档身份按 `版本|榜单类型` 生成，筛选条件不再参与榜单身份。
- 调整可见项目的档位后，将结果合并回完整榜单；隐藏项目不丢失、不回到待排名。
- 同行排序采用“替换可见位置”的规则：隐藏项目相互之间的顺序保持不变，最新可见项目顺序写回完整行。
- 例如完整同行为 `A、B、C、D`，筛选只显示 `A、C`；调整为 `C、A` 后，完整行成为 `C、B、A、D`。
- 同行顺序包括待排名区顺序；刷新、切换筛选和切换版本后均应恢复。
- 撤销按完整榜单隔离，切换筛选仍可撤销同一榜单的上一步操作。
- “重新排名”只重置当前筛选匹配的项目，隐藏项目保留；确认弹窗说明当前范围。
- 空筛选结果仍属于同一份完整榜单，不覆盖完整排名，也不创建临时存档身份。

### 3.3 国家特色继承

- 旧的两版共用九项特色榜迁移为“综合”。
- 原版或尤复特色榜尚未初始化时，从当前综合榜复制档位、同行顺序和标题。
- 继承是初始化时的快照。初始化后，三份榜的修改互不覆盖。
- 用户主动清空版本榜后，保留其独立存档，不在下次访问时自动填回综合排名。
- 用户晚些才首次进入另一个版本时，该空版本继承当时最新的综合榜。

### 3.4 旧存档迁移

- 新键：`ra2-tier-list:save:v3`；旧 `v1`、`v2` 键原样保留。
- 新状态：`schemaVersion: 3`、`catalogRevision: 2`。
- 支持国家榜 v1、多个筛选独立排名的 v2 迁移。
- v2 没有每次修改的时间戳，无法可靠还原全部历史先后。采用确定性规则：当前活动筛选优先；其余旧榜的已排项目填补未覆盖项目；保留可恢复的同行顺序。
- 同一项目在旧榜中存在冲突时，不能宣称一定恢复了最后一次操作；需在验收文档说明上述优先规则。
- 新增项目进入待排名，旧标题尽量保留。
- 若新键损坏或版本未知，应保护原数据，不能悄悄回退后覆盖。
- 若新版写入失败，旧键仍可恢复；页面应提示本次操作没有成功落盘。

## 4. 数据与素材策略

规则来源为本机 `D:\Red_Alet_II\YURI` 中原版档案与尤复补丁档案。只读提取，不能修改游戏安装。

当前生成入口：`scripts/prepare-0.4-catalog.py`；建筑科技链辅助文件：`scripts/prepare_catalog_helpers.py`。它以旧的已审核常规单位名录和原始采集 manifest 为输入，生成新版浏览器数据。

主要数据规则：

- 建筑采用 `BuildCat=Combat` 等原始字段区分两个类别，结合前置、阵营、国家限制和科技级别判断遭遇战可生产性。
- 建造厂通过基地车展开，是当前实现纳入常规榜的正常建筑；此项分类要在数据验收中核对。
- 尤复 `YADEPT` 的 `TechLevel=15`，已从常规建筑移至特殊建筑；不能仅凭“科技级别非负”认定可在普通遭遇战建造。
- 去除建筑注册表重复 ID，排除未定义实体、灯光／不可见辅助对象。
- 平民和动物没有菜单图时使用中立／阵营标志，原始 ID 保留以区分重名条目。
- `HORNET`、`ASW` 及 `MissileSpawn` 弹体不进入其他单位；运输机和支援飞机另行核对，不能一律按 `Spawned` 排除。
- 原版／尤复仍分开存储游戏条目。常规榜与特色子榜可以引用同一项目 ID，但不能共享排名状态。

1. 审查筛选后的修改、同行重排、待排名区重排、重置、撤销、标题修改及刷新恢复。
