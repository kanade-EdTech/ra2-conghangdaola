# 0.4.0 验收记录

日期：2026-10-16（Asia/Shanghai）。

## 实现结果

- 主导航为国家榜、常规榜、特色榜；特色榜分国家特色、T4 科技、其他单位、特殊建筑。
- 同版本、同类榜使用一份完整排名。类别、阵营、科技阶段和来源筛选只改变显示，档位、同行顺序和待排名区顺序写回完整排名并存到本机。
- 在筛选视图中交换同行项目时，替换对应的可见位置，隐藏项目的相互顺序与档位保留。重置只影响当前筛选；撤销跨筛选有效，各版本与各类榜隔离。
- 常规榜含普通单位、国家专属项目、T4 和遭遇战建筑；新增普通建筑、防御及超级武器类别，以及“间谍偷实验室后”科技阶段和国家专属屏蔽选项。
- 特色榜各子榜有适用筛选。全部平民人物、车辆、动物纳入其他单位；中立和战役建筑在特殊建筑独立排名。
- 国家特色支持最左侧的综合、原版、尤复三份榜。旧共享榜迁入综合，版本榜首次初始化时继承综合，之后独立；主动清空不会触发再次继承。
- 长列表每批显示 40 项，继续显示不改变实际排名。导出每页最多 50 项，可逐页预览、保存和切换 1080／720 宽度。
- 无独立图标、借用了无关单位图片或加载失败时，页面和海报使用阵营图标。特殊建筑卡片与海报增加内部代号区分同名条目。

## 数据复核

| 集合 | 原版 | 尤复 |
| --- | ---: | ---: |
| 普通常规单位 | 47 | 68 |

规则直接读取本机游戏原始档案。建筑依据 BuildCat、科技级别、前置链和国家限制分类。尤复维修厂 YADEPT 的科技级别为 15，放入特殊建筑；原版和尤复的复制中心、心灵建筑按各版规则分别归类。沙袋、围栏等墙体归防御。

复核中每版再排除 8 项路灯／不可见辅助对象，因此特殊建筑从中途版本的 241／327 项调整为 233／319 项。重复建筑 ID 去重，保留地图中的真实中立建筑、墙体、桥梁维修小屋等实体。弹体和 HORNET、ASW 等舰载子机排除；支援飞机不因 Spawned 字段一律排除。

国家专属屏蔽包括七种国家特殊兵种、巨炮和美国空指部。美国大兵不因伞兵能力而被屏蔽。美国伞兵能力仍在国家特色榜。

唯一现行生成入口为 `scripts/prepare-0.4-catalog.py`；旧两个生成脚本直接执行时转入现行入口，避免覆盖回旧范围。`data/unit-catalog.json` 是历史审核的普通单位／T4 输入；`data/runtime-unit-catalog.json` 是加入 national、spy、其他单位与建筑后的完整运行数据。生成不读取自己的输出作为命名输入，连续重生成的输出哈希一致。

## 存档与迁移

新键为 `ra2-tier-list:save:v3`，schemaVersion 为 3，catalogRevision 为 2。旧 v1／v2 键保留。

旧 v2 多份筛选榜没有操作时间戳，合并时以活动筛选为优先，其他旧榜的已排项目填补未覆盖项；新增内容进入待排名。该规则可以确定性恢复已有数据，但不能推断旧冲突项目真实的最后操作时间。

测试覆盖真实页面中 v2 活动筛选、标题、同行排序、隐藏苏军条目的恢复，以及旧键原始字节保留；v1 国家榜恢复也经过实际浏览器回归。损坏 v3 的保护提示和后续操作不覆盖旧数据均已验证。写入失败与未知版本保护由内置测试覆盖。
