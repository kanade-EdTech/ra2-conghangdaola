# 0.4.2 小红书包体优化

日期：2026-10-16。

在 0.4.1 精简范围上优化重复图标。保留国家榜、常规榜、国家特色和 T4；常规榜仍为原版 89 项、尤复 126 项，两个版本的项目 ID、数据和存档身份保持独立。

## 优化方式

构建期读取实际使用的图片，按 SHA256 查找内容完全相同的文件。每组只打包一个原文件，单位、建筑、国家特色、国旗和阵营回退图标引用同一个路径。按路径排序确定共享文件，因此结果可重现。

图标不做重绘、缩放或有损转换。两个版本的图片内容不同则分别保留；不能仅因为名称相同就强行合并。运行数据在构建期写入最终共享路径，无需在运行时加载原版／尤复两套重复图片。图片共享不合并版本排名或规则数据。

删除 88 个重复图片副本；最终 ZIP 缩小 39.46%。原 0.4.1 和 Toy 0.4.0 发布包保留，哈希未变。

## 验证

31 项内置测试通过。其中新增测试逐条比较优化前后的单位、建筑、国家与国家特色元数据，并对每个显示图标比较原始字节 SHA256；所有图片引用均在最终包内，不再有重复 PNG 内容。

23 项浏览器检查通过：全部 138 个共享和回退图标加载成功，原版／尤复常规范围、T4、国家特色继承、旧存档迁移、刷新恢复、结果图导出和模拟桥接保存均正常；320／390／430 像素无横向溢出。脚本为 scripts/browser-xhs-0.4.2.js。

静态检查与小红书 ZIP 审计通过，0 警告；CRC 正常，ZIP 内容与 dist/xhs 逐文件一致。未实测小红书真机和 Chrome 61，相册保存使用模拟桥接。

重建命令：npm run build:xhs、npm run check:xhs、npm run package:xhs。产物为 release/ra2-tier-list-xhs-0.4.2.zip；SHA256 等记录在 release/0.4.2-artifact-manifest.json。
