# 0.4.3 发行说明

日期：2026-10-18。

## 本次变化

- 修复手机查看长榜单结果图时，保存按钮在视野之外、关闭按钮随弹窗滚动消失的问题。图片独立滚动，关闭、翻页、保存及画质切换保持可见，支持键盘滚动预览。
- Toy 保留国家榜、常规榜，以及国家特色、T4、其他单位和特殊建筑。
- 小红书保留国家榜、常规榜、国家特色及 T4；移除其他单位、特殊建筑及专用资源。相同图片按内容合并，138 个图标文件供不同版本项目共用，各版本项目和排名独立。
- 小红书使用独立存档键，首次可继承完整版本的兼容旧存档，并保留原存档。

## 验证

31 项自动测试通过。界面修复验收包括 163 项浏览器检查；覆盖筛选、排名持久化、触屏同行排序、多指取消、图片分页、轻量画质和模拟相册保存。两端静态检查及离线包审计通过后发行。

浏览器检查使用桌面 Chrome 与触摸模拟；B站／小红书 App 真机及 Chrome 61 兼容性未实测。
