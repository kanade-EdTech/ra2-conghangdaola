# 红警 2「从夯到拉」开发提示词

更新日期：2026-10-12  
配套规范：[开发计划.md](开发计划.md)

## 使用方式

总开发提示词适合在项目根目录交给编程助手推进完整首版；分阶段提示词适合分次执行或修改已有实现。整段复制对应代码块即可。先让助手读取配套开发计划，阶段编号与计划保持一致。

平台方法与参数以实施时可读取的官方文档／本机技能 references 为准，不凭方法名字猜测。本文件描述后续开发任务，不表示功能已经实现或平台已经验收。

## 一、总开发提示词

```text
你是一名熟悉移动端 H5、离线 WebView、Canvas 2D 和中文互动工具的前端工程师。请在当前项目开发「红警 2：从夯到拉」，适配 B 站 Toy 与小红书小工具。

先读取 AGENTS.md、README.md、docs/开发计划.md，检查已有文件和未提交修改，尊重用户现有工作。读取可用的 minitool-zip-builder 和 toy 技能及相关 references。只有确实缺少必要信息时提问，其余按开发计划推进。

目标是完成本地首版实现、必要验证和两个平台的静态候选包。本次不上传或提交平台审核。

【范围】
1. 原版 9 国：美国、英国、法国、德国、韩国、苏俄、伊拉克、古巴、利比亚。
2. 尤复保留上述 9 国并加入尤里，共 10 项。尤里是阵营，界面使用「国家／阵营」；稳定 ID 和识别标签遵循计划。
3. 自上而下五档：夯、顶级、人上人、NPC、拉。待排名是独立区域。
4. 默认原版，全部初始待排名；不预设所谓官方／公认强度榜。
5. 只做国家／阵营。不要加入 MOD、兵种建筑榜、在线投票、公共排行榜、登录、服务器或云同步。

【操作与状态】
1. 两版本独立保存排名、标题和会话撤销历史，切换不复制、不清空、不串档。
2. 支持点击卡片选档、鼠标／触摸拖拽、跨档、同档重排、移回待排名。
3. 操作面板提供换档、前移、后移和移回待排名，保证不拖拽也能完成全部操作。
4. 标题最多 30 个 Unicode 码点，按纯文本展示；改标题不自动改排名。
5. 每版本会话内保留最近 20 次提交的修改；一次拖放只算一次；取消或位置未变不计入历史。
6. 重置需确认，只重置当前版本排名、保留标题，并可撤销。
7. 自动保存本地草稿，刷新恢复。存储不可用、配额不足、损坏存档和未知 schema 均有处理；失败不阻止排名和导出。
8. 每个有效 ID 恰好出现一次，五档与待排名区的并集恰好等于当前版本名单。修改先校验下一状态再提交。

【技术与平台】
1. 无既有构建链时使用 HTML、CSS、ES2017 原生 JS、Canvas 2D。按数据、规则、存储、界面、拖拽、导出、平台适配拆分职责。
2. 外置经典脚本通过相对 src 加载，事件用 addEventListener，依赖顺序明确；数据直接随脚本提供，不 fetch 本地 JSON。
3. 小红书最终包兼容 Chrome 61：无 type=module、运行时 import/export、动态 import、内联 JS、行内事件、eval/new Function、WASM、Worker、Service Worker、联网、外链跳转、剪贴板和下载 API。
4. 所有资源随包，无 CDN、远程图片或字体；不添加自建 CSP meta、base、iframe 或 object。
5. CSS 使用 Chrome 61 基线，Flex 间距使用 margin，不以 gap、clamp、aspect-ratio 或新视口单位作为唯一实现。
6. 一套业务核心，构建时分别选 Toy／小红书适配器；小红书包不能残留浏览器下载等被禁实现。两个 ZIP 根目录都是 index.html。
7. Toy 在子路径验证资源，无需 history 路由和云 SDK；真实 B 站 App 内保存另行实测，不编造保存 API。
8. 小红书桥只用文档列出的 window.xhs.miniTool.*。保存链路为 writeTempFile({data: 完整dataURI}) → saveImageToPhotosAlbum({filePath})；先检测能力，参数和返回字段以文档为准。
9. Bridge 不存在／权限被拒时保留预览与榜单，提供清晰反馈和重试／系统截图方式。小红书不能以长按图片保存或 a[download] 兜底。

【界面与图片】
1. 深灰作战面板、克制的金属边框、红色强调、五档色条；盟军蓝／苏军红／尤里紫只作小型标识。卡片名称清楚。
2. 手机优先，支持 320–430px 和桌面，热区至少 44px。处理正常滚动、拖拽取消、边缘滚动、底部安全区、软键盘与键盘焦点。
3. 图标先用原创几何徽记／文字也可，缺图有回退；不捆绑原版资源包、音乐或视频。
4. Canvas 从状态重绘海报，不截图 DOM。默认宽 1080px，高度自适应，包含标题、版本、五档、卡片与完成数量。
5. 未排完也可导出，保留待排名区和已排 X/N；空档保留，顺序一致。
6. 处理长标题、图标失败、全部项目同档和内存不足；支持低分辨率重试，关闭预览释放资源，不永久存储海报 Base64。

【实施与交付】
1. 按 M0 兼容性小样 → M1 核心闭环 → M2 交互存档 → M3 图片 → M4 双端打包 → M5 验收推进。
2. 重点测试计数、移动不变量、版本隔离、撤销、损坏存档，再验证实际点选、拖拽、导出流程。
3. 审计最终 dist 与 ZIP：根入口、相对路径、资源存在、经典脚本、ES2017、禁用 API、包体和无开发垃圾文件。
4. 小红书按当前技能门禁 ≤10 MiB，目标 ≤2 MiB；Toy 不编造上限。运行现有预检／审计工具，无法运行时记录人工检查和原因。
5. 真机、旧内核或平台容器不可用时写「未实测」，不伪造通过，不停止可继续的本地工作。
6. 更新 README 的运行、打包和产物说明。交付两平台 ZIP、可获得的关键截图和验收记录，说明实际检查与剩余限制。

现在开始检查项目并实现。不要只给计划；完成当前环境允许完成的实现和验证。
```

## 二、分阶段提示词

### M0：平台小样与名单定稿

```text
读取 docs/开发计划.md，完成 M0。

检查项目与适用技能。做最小单页：外置经典脚本、包内图标、Canvas 绘图、localStorage 读写、小红书保存能力检测。分别准备 Toy／小红书本地产物，不上传平台。

核对 10 条实体数据与原版 9／尤复 10 的筛选结果，ID 使用计划定义；不添加 MOD 或将尤里放进原版。

小红书 writeTempFile 与 saveImageToPhotosAlbum 只按已读 references 实现。无真实容器时可模拟成功／失败验证应用分支，但必须注明模拟不是平台验收。记录脚本、路径、离线、Canvas 与存储的实际检查，以及待真机验证项。

交付最小可运行产物、数据定稿和兼容性记录，停止在 M0 边界，不发布。
```

### M1：核心排名闭环

```text
读取 docs/开发计划.md，基于已有代码完成 M1。

实现国家数据、纯排名规则、两个版本、五档与待排名区、点选分档、卡片操作面板。支持换档、前移、后移和移回待排名，此阶段不拖拽也能完成全部排名。

保持 9／10 项正确，每个 ID 恰好出现一次，两版本独立。移动先计算完整下一状态并校验，再更新 UI。标题纯文本，最多 30 个 Unicode 码点。

使用 ES2017 经典脚本与相对资源。克制的红警作战台风格，手机优先，空档提示和 44px 热区；无图标时用文字徽记。

为初始化、跨档、同档重排、移回待排名、版本隔离提供必要测试，检查手机与桌面布局。交付可打开产物和实际检查结果，不做网络功能或发布。
```

### M2：拖拽、撤销与存档

```text
读取 docs/开发计划.md，在已有 M1 上完成 M2。

实现 Pointer Events 拖拽与必要的 Touch／Mouse 回退，处理手柄、局部 touch-action、目标提示、边缘滚动、pointercancel 和拖出容器。保留页面自然滚动，松手只提交一次，取消或位置未变不入撤销历史。

实现各版本独立的 20 步撤销、重置确认和自动存档。重置仅清空当前版本排名、保留标题且可撤销。版本切换前尝试落盘。

存档验证 schema 与类型；已知格式去除无效／重复 ID，补齐缺失 ID。不可修复／高版本存档不静默覆盖。读取或写入失败仍提供内存模式，准确提示未保存。

测试版本独立撤销、重置取消与撤销、拖动取消、损坏存档、未知 schema、读写异常；实测滚动与拖拽，缺真机注明未测。交付实际结果与剩余问题。
```

### M3：结果图与保存

```text
读取 docs/开发计划.md，完成 M3。

用 Canvas 2D 从状态重绘，默认宽 1080px，高度按内容计算。包括标题、版本、五档、卡片、已排 X/N；未排完时增加待排名区。保留空档和同档顺序，长标题换行，缺图回退文字徽记。

不依赖 DOM 截图库、远程资源或网络。只在生成时绘制；用户点击保存才走保存流程。处理内存不足、重复点击、序列化异常和低分辨率重试，关闭预览释放资源。

平台适配分别实现：
- 浏览器尝试下载并保留预览；触发下载不能直接声称已保存。
- Toy 先保证预览，按真实宿主验证保存，不猜 API。
- 小红书检测 window.xhs.miniTool，完整 data:uri 传 writeTempFile({data})，返回 filePath 后传 saveImageToPhotosAlbum({filePath})；失败保留图片与榜单；无桥时提示系统截图，不使用下载 API 或长按保存。

小红书包排除浏览器下载代码。验证空榜、满榜、未排名、全在一档、长标题、缺图与拒绝授权；交付样例图片及检查记录，平台未测项如实注明。
```

### M4：双平台打包与审计

```text
读取 docs/开发计划.md 和当前平台技能 references，完成 M4。

生成 dist/toy、dist/xhs 和 release 下两个 ZIP。压缩目录内容，两包根目录直接含 index.html；仅放运行必需文件，不带 .git、node_modules、source map、构建配置、开发文档和 toy.yaml。

检查最终包资源路径与文件存在。小红书只有外置经典脚本，不残留 import/export、内联事件、联网、下载、剪贴板、WASM、Worker 等被禁实现；名单不 fetch JSON。核对 ES2017 和 Chrome 61 CSS 回退，不能只检查源码。

查看现有审计脚本帮助，使用本机可用 Node／Python 运行小红书目录／ZIP 审计和 Toy 内容预检；修复 ERROR、审查 WARN，补充人工检查。

在 Toy 风格的嵌套子路径加载，确认无资源 404。封面与图标分别准备，依据当前指南，不编造尺寸或体积上限。

更新 README 打包说明，输出 ZIP 大小、文件清单和审计结果。仅本地交付，不上传或提交审核。
```

### M5：验收与修复

```text
按 docs/开发计划.md 验收当前实现与最终包，发现问题直接修复，并针对改动复测。

重点检查：9／10 名单；每 ID 恰好一次；点选与拖拽的顺序一致；取消不改变状态；两个版本排名和撤销隔离；重置确认；损坏存档及存储异常；手机滚动、安全区、软键盘、键盘焦点；图片不漏项、不裁切；保存失败与 Bridge 缺失有反馈；Toy 子路径和小红书离线运行。

按静态检查、桌面运行、平台模拟、实际 App／真机、旧内核分别记录证据。模拟接口不能证明真实平台支持。缺少环境写未实测，不编造截图、性能或审核结果。

交付修复清单、实际测试、未测项和最终产物位置，停止在本地候选版本交付，不自动发布。
```

## 三、视觉优化专项提示词

```text
请在保持 docs/开发计划.md 功能规则的前提下，优化「红警 2：从夯到拉」界面。

深灰作战台、克制金属边框与红色强调；五档依次为夯、顶级、人上人、NPC、拉，色条鲜明。盟军蓝／苏军红／尤里紫只作小标识。排名和名称优先，不用大面积纹理、持续闪烁、3D、粒子或背景视频。

保留 ES2017／Chrome 61 基线，不引入外部字体、图标 CDN 或远程背景；本地原创图标／文字徽记即可。

直接修改并检查 320／375／390／430px 与桌面布局，交付实际截图或检查结果。不改变排名逻辑、名单和产品范围。
```
