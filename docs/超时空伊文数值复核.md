日期：2026-10-15。直接读取本机游戏档案，未修改游戏或应用。

对照来源：原版 `ra2.mix::local.mix::rules.ini`；尤复 `ra2md.mix::localmd.mix::rulesmd.ini`，另核对补丁 `expandmd01.mix::rulesmd.ini`。这里列出的尤复数值在基础档案与补丁档案中一致。原字段与完整规则文件 SHA256 见 [复核数据](../data/chrono-ivan-verification.json)。

重要更正：此前把两版 `IvanBomber.Damage=400` 当成装设炸药威力不变的依据，遗漏了全局 `IvanDamage`，该结论不正确。原文件明确注释 `Damage is used only for death explosion`；定时炸药另用 `CombatDamage.IvanDamage`。因此尤复装设炸药基础伤害增加 12.5%，最终伤害还受装甲倍率等影响。IvanWH 的装甲倍率与范围在这两份规则中一致。

尤复武器另有 `FireInTransport=no`，原文件注释为不能从战斗要塞内开火。应理解为不能在开放射击运输载具中装设炸药，不能据此说他无法乘车，也不能据此推断原版拥有战斗要塞内开火能力；原版没有战斗要塞。

结论：两版确实存在成本、炸药威力和获取条件差异，主要瞬移参数与基本生存数值不变。
